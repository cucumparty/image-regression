# Age Prediction from Photographs

This project utilizes a convolutional neural network model based on the ResNet50 architecture to predict the approximate age of a person from their photograph. The model is built using Keras and TensorFlow, leveraging transfer learning for improved accuracy.

## Table of Contents

- Features
- Prerequisites

## Features

- Predicts approximate age from images of faces.
- Based on the ResNet50 architecture for enhanced accuracy.
- Utilizes transfer learning for efficient training.

### Prerequisites

Make sure you have Python installed. This project requires the following libraries:

- TensorFlow
- Keras
- NumPy
- OpenCV
- Matplotlib
- Pandas
